# QR Generator and Scanner System

A full-stack QR Generator and Scanner web application built using React, Java Servlet, JDBC, and MySQL.

## Tech Stack

- React.js
- Java Servlet
- JDBC
- MySQL
- ZXing
- Apache Tomcat

## Features

- QR Generation
- QR Scanning
- Authentication
- Scan History
- Dashboard
